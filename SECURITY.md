# Security policy

Photo Duplicate Cleaner works with private media and can move approved items to Photos' Recently Deleted area. Reports that could cause data loss, expose library metadata, or bypass confirmation are especially important.

## Supported versions

Security fixes are made on the latest release and the default branch. Older versions may not receive fixes.

## Reporting a vulnerability

Use GitHub's **Security** tab to submit a private vulnerability report. If private reporting is unavailable, open a minimal issue asking the maintainers for a private contact channel; do not include exploit details, photos, exported journals, asset identifiers, filenames, or location data in a public issue.

Include the affected version or commit, macOS version, impact, and minimal reproduction steps using synthetic data when possible. Please allow the maintainers time to investigate before public disclosure.
